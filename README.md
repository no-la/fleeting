# fleeting

いまを、一枚に。Twitter Fleets に着想を得た、スマートフォン向けのストーリー画像エディタです。Twitter / X とは関係のない独立したプロジェクトです。

## できること

- 9:16 の画像に日本語テキストを配置、ドラッグ・矢印キーで移動
- 3 書体、文字サイズ、色、揃え、文字背景
- 8 色のグラデーション、任意の背景色、写真の読み込み・明るさ調整
- 1080 × 1920 PNG のダウンロード
- ブラウザの localStorage に下書きを自動保存

写真はブラウザ内で縮小・処理します。アップロードやアカウント、SNS 機能はありません。下書きはブラウザごとに保存され、容量不足やプライベートモードでは保存できないことがあります。写真は中央を基準にトリミングします。動画・自由な写真トリミングには未対応です。画像は端末のダウンロード先に保存されます。

## 開発

ビルドや依存パッケージは不要です。

```sh
python3 -m http.server 8080
```

http://localhost:8080 を開きます。`main` ブランチのルートを GitHub Pages で配信します。
