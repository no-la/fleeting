# fleeting

[エディタを開く](https://no-la.github.io/fleeting/)

Twitter Fleets の編集画面を参考にした、スマートフォン向け静的画像エディタです。Twitter / X とは関係のない個人制作です。

## 編集の流れ

1. キャンバスをタップ、または **Aa** でテキストを追加します。
2. 入力中に文字揃え・太字・文字背景・色を選び、**完了** を押します。
3. 文字はドラッグで移動、2本指で拡大縮小・回転。タップすると再編集できます。
4. 複数のテキストや絵文字を配置できます。下のゴミ箱にドラッグして削除、上の矢印で元に戻せます。
5. 左下の丸から背景を変更。**カメラロール** で写真選択、**撮影** で端末のカメラを開きます（端末によってはファイル選択画面になります）。
6. 右上の **保存** で画像のプレビューを開きます。**保存・共有** から端末の共有メニューへ進み、iPhoneでは **画像を保存** を選びます。共有に対応していないブラウザでは、プレビューの長押し・右クリックで保存できます。ファイルのダウンロードは **ファイルとして保存** から選べます。出力は 1080 × 1920 の PNG です。

パソコンでは、文字を選んで矢印キーで移動できます。調整ボタンからサイズ・角度も変更できます。
文字・絵文字のサイズは24〜1920で、スライダーとピンチ操作の両方から変更できます。大きくしたノードは画面外にはみ出して配置できます。

## 絵文字

Unicode Emoji 18.0 の `emoji-test.txt` から、fully-qualified と component の全3,972件を収録しています。黒背景の全画面に検索欄と3列の絵文字を並べ、スクロールで続きを自動表示します。日本語・英語・絵文字で検索でき、未表示の候補も含む全件が対象です。最近使った絵文字は先頭に表示します。

肌色違いは1つにまとめ、長押しまたは右下の三角ボタンで選べます。複数人の肌色の組み合わせ、国旗、家族・職業などの結合絵文字も選択可能です。

データはこのサイトに同梱し、ピッカーを開いたときだけ読み込みます。日本語名とキーワードには Unicode CLDR を使用しています。端末が未対応の新しい絵文字は、四角や分かれた文字で表示されることがあります。

- [Unicode Emoji データ](https://www.unicode.org/Public/emoji/latest/emoji-test.txt)
- [Unicode CLDR 日本語注釈](https://github.com/unicode-org/cldr-json/tree/main/cldr-json/cldr-annotations-full/annotations/ja)
- [同梱データのライセンス](data/UNICODE-LICENSE.txt)

取得元とSHA-256は `data/emoji.json` に記録しています。データを更新する場合は `scripts/build-emoji-data.py` に記載の4ファイルを取得し、`python3 scripts/build-emoji-data.py <取得先ディレクトリ>` を実行します。

## 範囲とデータ

- 投稿・SNS・動画・GIF検索には対応していません。
- 写真は中央に全体表示し、背景メニューから全面表示へ切り替えられます。写真そのものの自由な移動・回転は未対応です。
- 写真はブラウザ内で縮小・処理し、サーバーには送信しません。
- 下書きは localStorage に自動保存。容量不足やブラウザの設定によっては保存できません。
- 初版の下書きは新形式へ移行します。書体・背景は近い設定への変換となります。
- 端末のフォントや絵文字の違いにより、見た目に差があります。

## 開発

ビルドや依存パッケージは不要です。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

http://127.0.0.1:8765 を開きます。`main` ブランチのルートを GitHub Pages で配信します。

構文確認：`node --check app.js`

絵文字データ・検索・絞り込みのテスト：`node --test tests/emoji-picker.test.mjs`

中央の案内文は新規キャンバスだけに表示し、編集開始後は空に戻しても再表示しません。「新しく作る」でリセットすると再び表示します。

ブラウザで直接入力・装飾・複数レイヤー・ドラッグ・2点タッチによる拡大縮小と回転・削除と取り消し・写真読み込み・下書き復元・PNG書き出しを検証しています。モバイル寸法とキーボード相当の縮小ビューポートを含みますが、実機 iOS / Android でのキーボード・カメラ確認は未実施です。

保存・共有は Web Share API の対応状況で切り替えます。共有ボタンを押す前にPNGファイルを作り、ユーザー操作直後に共有APIを呼び出します。APIへのファイル受け渡し・キャンセル・非対応時のプレビュー・任意のダウンロードをブラウザで検証しています。iPhone実機の共有メニューおよび写真アプリへの保存は未確認です。
